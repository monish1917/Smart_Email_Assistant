# Smart Email Assistant

## Overview

Smart Email Assistant is an AI-powered email generation tool built using n8n and Google Gemini.

It helps users generate professional emails for different scenarios.

## Features

- Job Application Emails
- Leave Requests
- Meeting Invitations
- Complaint Emails
- Customer Support Emails
- Follow-up Emails
- Formal/Friendly/Persuasive/Concise writing styles
- Grammar Improvement
- Email Regeneration
- Context Memory

## Technologies

- n8n
- Google Gemini API
- Simple Memory
- AI Agent

## Workflow

Chat Trigger
↓
AI Agent
├── Google Gemini Chat Model
└── Simple Memory

## Output

Generates clean professional emails.
